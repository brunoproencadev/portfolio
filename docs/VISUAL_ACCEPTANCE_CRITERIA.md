## Método de comparação

Para cada componente: referência com arquivo/timestamp → captura do mesmo estado de implementação → discrepância concreta → decisão → evidência após ajuste. Capturar desktop 1440×900 e 1920×1080, mobile 375×812; exercitar também 320/768px, viewport curto e zoom 200%. As gravações externas só demonstram desktop; mobile será adaptação explicitamente avaliada, não fidelidade alegada a vídeo inexistente.

Comparar geometria normalizada pelo viewport/conteúdo, não fazer pixel diff entre textos/identidades diferentes. Após a Fase B aprovar composição e tokens, fixar screenshots internos como baseline; referências não são goldens pixel-perfect. Medidas de referência têm aproximações descritas na análise. Para movimento, gravar execução real e extrair antes/durante/depois; relógio simulado ajuda regressão, mas não comprova fluidez real.
