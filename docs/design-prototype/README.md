# Protótipo documental da Fase B

Abra [index.html](index.html) em um navegador. CSS, fonte e mídias são locais. [states.html](states.html) apresenta ilha e storyboard. Não é uma segunda aplicação: não possui package.json, build, roteador ou integração com Next.

Menu usa details/summary nativo, sem animação, por clique/Enter/Espaço. Escape, seção ativa dinâmica, fechamento externo e foco de destino pertencem à futura Fase C. Links de case abrem páginas já publicadas; links de projeto/contato usam destinos reais. Rodapé identifica o estudo, não será copiado ao produto.

Proveniência: [MEDIA_ASSETS](../MEDIA_ASSETS.md). Manrope Latin variável local, [licença SIL OFL 1.1](fonts/OFL.txt), [origem e hashes](fonts/source.json). Saudação vetorial é desenho original de estudo, nunca assinatura pessoal.

Evidências em [PHASE_B_REVIEW](../PHASE_B_REVIEW.md). Estados estáticos não validam movimento; gravações/continuidade serão C–F. Performance do protótipo não equivale ao app Next. Não publicar este diretório como site final.
